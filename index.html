Activity Guide Format

Standardized format for hands-on STEM activities

Section 1 Overview

Activity Overview

Title, grade level, duration, group size, STEM domain, learning objectives, and standards alignment (NGSS, CCSS, CSTA).

  1. Title & Description: Clear, engaging activity name with brief description
  2. Grade Level: K-2, 3-5, 6-8, 9-12, or multi-grade
  3. Duration: Minutes for single session or multi-day breakdown
  4. Group Size: Individual, pairs, small groups (3-4), whole class
  5. STEM Domain: Science, Technology, Engineering, Mathematics, or Integrated
  6. Objectives: 3-5 measurable learning outcomes using Bloom's taxonomy verbs
NGSS Aligned CCSS Aligned
Section 2 Materials

Materials & Preparation

Complete materials list with quantities, prep steps, safety considerations, and technology requirements.

  1. Materials List: Item, quantity per group, cost estimate, sourcing notes
  2. Prep Steps: Numbered advance preparation tasks with time estimates
  3. Safety: PPE requirements, hazard warnings, emergency procedures
  4. Technology: Software, hardware, accounts needed, backup plans
  5. Accessibility: Alternative materials, differentiation options for diverse learners
Safety Checklist Cost Estimates
Section 3 Procedure

Step-by-Step Procedure

Detailed facilitation script with timing, teacher moves, student actions, discussion prompts, and formative assessment checkpoints.

  1. Introduction (5-10 min): Hook, activate prior knowledge, state objectives
  2. Exploration (15-30 min): Guided inquiry, hands-on investigation, data collection
  3. Sense-Making (10-15 min): Group discussion, pattern identification, concept development
  4. Application (10-20 min): Extension challenges, real-world connections, transfer tasks
  5. Reflection (5-10 min): Exit ticket, self-assessment, questions for next time
Timing Guide Formative Checks
Section 4 Assessment

Assessment & Extensions

Formative and summative assessment strategies, rubrics, differentiation, and extension activities.

  1. Formative: Observation checkpoints, questioning strategies, student work analysis
  2. Summative: Rubrics for products, presentations, portfolios, written explanations
  3. Differentiation: Tiered challenges, language supports, scaffolding options
  4. Extensions: Deeper investigation, cross-curricular connections, home connections
  5. Resources: Vocabulary cards, anchor charts, digital tools, literature links

Validator Script & Example

Automated validation of lesson plan completeness

Validator Script

#!/usr/bin/env python3
"""STEM Facilitator Toolkit - Lesson Plan Validator
Validates YAML lesson plans against required schema."""
import yaml
import sys
from pathlib import Path
from typing import Dict, List, Any

REQUIRED_SECTIONS = [
    "overview", "materials", "procedure", "assessment", "extensions"
]

REQUIRED_OVERVIEW_FIELDS = [
    "title", "description", "grade_level", "duration_minutes",
    "group_size", "stem_domain", "objectives", "standards"
]

def validate_lesson_plan(filepath: Path) -> List[str]:
    errors = []
    with open(filepath) as f:
        plan = yaml.safe_load(f)

    # Check required top-level sections
    for section in REQUIRED_SECTIONS:
        if section not in plan:
            errors.append(f"Missing required section: {section}")

    # Validate overview
    if "overview" in plan:
        for field in REQUIRED_OVERVIEW_FIELDS:
            if field not in plan["overview"]:
                errors.append(f"overview missing required field: {field}")

        # Check objectives count
        objectives = plan["overview"].get("objectives", [])
        if len(objectives) < 3:
            errors.append("overview.objectives: minimum 3 objectives required")

    # Validate procedure has steps
    if "procedure" in plan:
        steps = plan["procedure"].get("steps", [])
        if len(steps) < 3:
            errors.append("procedure.steps: minimum 3 steps required")

    # Validate assessment has rubric
    if "assessment" in plan:
        if "rubric" not in plan["assessment"]:
            errors.append("assessment missing required field: rubric")

    return errors

def main():
    if len(sys.argv) < 2:
        print("Usage: python validate.py ")
        sys.exit(1)

    filepath = Path(sys.argv[1])
    if not filepath.exists():
        print(f"File not found: {filepath}")
        sys.exit(1)

    errors = validate_lesson_plan(filepath)
    if errors:
        print("VALIDATION FAILED:")
        for error in errors:
            print(f"  - {error}")
        sys.exit(1)
    else:
        print("VALIDATION PASSED")
        sys.exit(0)

if __name__ == "__main__":
    main()

Example Lesson Plan

overview:
  title: "Bridge Building Challenge"
  description: "Students design and test bridge structures using limited materials"
  grade_level: "6-8"
  duration_minutes: 90
  group_size: "3-4"
  stem_domain: "Engineering"
  objectives:
    - "Apply the engineering design process to solve a structural problem"
    - "Analyze how geometric shapes affect structural strength"
    - "Communicate design decisions using evidence from testing"
  standards:
    - "NGSS: MS-ETS1-1, MS-ETS1-2, MS-ETS1-3"
    - "CCSS.MATH: 7.G.A.1"

materials:
  - item: "Popsicle sticks"
    quantity_per_group: 50
  - item: "Wood glue"
    quantity_per_group: 1
  - item: "Weights for testing"
    quantity_per_group: 1

procedure:
  steps:
    - phase: "Introduction"
      duration_minutes: 10
      teacher_actions: ["Show bridge images", "Discuss forces"]
      student_actions: ["Observe", "Ask questions"]
    - phase: "Design"
      duration_minutes: 20
      teacher_actions: ["Circulate", "Prompt thinking"]
      student_actions: ["Sketch designs", "Plan builds"]
    - phase: "Build"
      duration_minutes: 30
      teacher_actions: ["Monitor safety", "Answer questions"]
      student_actions: ["Construct bridges", "Iterate"]
    - phase: "Test"
      duration_minutes: 20
      teacher_actions: ["Add weights", "Record results"]
      student_actions: ["Test bridges", "Record data"]
    - phase: "Reflect"
      duration_minutes: 10
      teacher_actions: ["Facilitate discussion"]
      student_actions: ["Analyze results", "Share insights"]

assessment:
  rubric:
    criteria:
      - name: "Design Process"
        levels: ["Exemplary", "Proficient", "Developing", "Beginning"]
      - name: "Structural Integrity"
        levels: ["Exemplary", "Proficient", "Developing", "Beginning"]
      - name: "Team Collaboration"
        levels: ["Exemplary", "Proficient", "Developing", "Beginning"]
      - name: "Scientific Communication"
        levels: ["Exemplary", "Proficient", "Developing", "Beginning"]

extensions:
  - "Test bridges with dynamic loads (shaking table)"
  - "Research real-world bridge designs"
  - "Calculate cost-efficiency ratios"
